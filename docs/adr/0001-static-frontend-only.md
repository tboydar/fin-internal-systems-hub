# ADR 0001：純前端，沒有後端

- 狀態：已採用
- 日期：2026-11-24

## 背景

這是作品集 Demo，放在 GitHub Pages。看的人是獵才顧問、資訊主管，以及不懂技術的財務或人資主管，
他們點開網址就要能看，不會去申請帳號，也不該被要求信任一個來路不明的後端。

## 決定

整個網站是靜態檔案。沒有後端、沒有 API 金鑰、沒有追蹤碼，不呼叫任何外部服務。

- 資料由 `src/mock/` 用固定種子產生，每次建置結果相同。
- 使用者的操作存在 `localStorage`（鍵值都以 `fish:` 開頭），可以一鍵還原。
- 路由用 hash（`#/overview`），資源用相對路徑，所以 repo 改名、換子路徑、重新整理都不會 404。

## 代價

- 不能示範真的多人協作，也沒有真的權限管控：權限矩陣存在瀏覽器裡，懂的人改得掉。畫面上講的是「誰該看到什麼」，不是安全機制。
- 「同一件事，不同說法」的句子由規則組出來（`src/core/narrative.ts`），不是語言模型寫的。好處是每次結果一樣、能寫測試；壞處是只涵蓋寫了規則的情況。

## 怎麼守住

- `tests/unit/provenance.test.ts`：程式裡除了作者連結沒有任何網址，也沒有用到連線、Cookie 或定位的 API。
- `tests/e2e/smoke.e2e.ts`：走過每一頁，瀏覽器只向網站本身拿靜態檔案。
