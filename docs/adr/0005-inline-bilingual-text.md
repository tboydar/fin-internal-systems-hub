# ADR 0005：雙語文字就地寫成一對，不另開字典檔

- 狀態：已採用
- 日期：2026-11-24

## 背景

姊妹作（energy-saas-rd-hub）用兩份字典檔 `zh.ts`／`en.ts`，以 key 取字，英文少一個 key 就編譯失敗。
這個做法可行，但每加一句話要想一個 key、改兩個檔，讀程式時也看不到畫面上到底寫什麼。

## 決定

中文與英文就地寫成一對：

```ts
T('重送 {n} 筆', 'Resend {n} {n|record|records}', { n });
```

- 兩個參數都是必填，少翻一邊在編譯時就會報錯。保證跟字典檔一樣，但文字就在用到它的地方。
- 假資料用同樣的形狀：`L('傳票', 'Voucher')`，畫面用 `tx()` 依目前語言取值。
- 英文的單複數寫成 `{n|record|records}`。

## 代價

- 沒辦法把所有文字交給譯者一次處理；要加第三種語言就得改每一個呼叫。對只有中英兩種語言的 Demo，這個代價可以接受。
- 一行會比較長。

## 怎麼守住

- `tests/unit/mock.test.ts`：每筆雙語文字都有中文與英文，英文裡沒有中文字。
- `tests/e2e/smoke.e2e.ts`：切到英文後走過每一頁，畫面上不能有殘留的中文。
